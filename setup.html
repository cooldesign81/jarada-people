계정 확인

최초 관리자(최고관리자) 계정을 등록하기 위한 페이지입니다. 구글 계정으로 로그인하면 Firebase가 부여한 고유 ID(UID)를 확인할 수 있습니다.
이미 권한이 등록된 분은 앱 화면으로 바로 이동하세요.

내 UID

아래 값을 복사해서 Firestore의 roles 문서 ID로 사용합니다.

UID
—

다음 단계

  1. Firebase 콘솔 → Firestore → 데이터 탭
  2. 컬렉션 시작 → 컬렉션 ID를 roles 로 입력
  3. 문서 ID 칸에 위 UID를 그대로 붙여넣기 (자동 ID 쓰지 말 것)
  4. 필드 3개 추가:
    level (문자열) = super
    orgId (문자열) = hq
    employeeId (문자열) = emp_0001
  5. 저장 후 이 페이지를 새로고침하면 아래 상태가 바뀝니다
  6. 권한이 확인되면 앱 화면으로 이동해 조직과 직원을 등록합니다. 이후 직원은 이 페이지 없이 바로 로그인하면 됩니다.
